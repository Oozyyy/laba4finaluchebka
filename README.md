ЧистоДом: клининговые услуги (React + Node.js/Express + SQLite)

Фронтенд (корень проекта):
  npm install
  npm run dev       сайт на http://localhost:5173

API (папка server, второй терминал, нужен Node.js 22.13 или новее):
  cd server
  npm install
  npm start         API на http://localhost:4000, база создаётся автоматически
